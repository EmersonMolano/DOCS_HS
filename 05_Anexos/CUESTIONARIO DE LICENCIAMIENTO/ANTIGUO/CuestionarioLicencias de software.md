<p><div class="text-box">1. ¿Qué es una licencia de software?<p>Es un permiso que te da el creador para usar un programa bajo ciertas reglas.</p>1. ¿Por qué es importante tener una licencia de software?<p>Porque asegura que uses el software de forma legal y con derechos claros.</p>1. ¿Cuáles son los diferentes tipos de licencias de software?<p>&emsp;Gratuitas, de pago, libres, de código abierto, privativas, entre otras.</p>1. ¿Qué es el código fuente y cómo se relaciona con las licencias de software?<p>Es la base del programa (su “receta”). Según la licencia, puede ser abierto (lo puedes   ver y modificar) o cerrado (solo el creador lo controla).</p>1. ¿Qué es el software libre y cuáles son sus características?<p>Es aquel que puedes usar, estudiar, modificar y compartir libremente.</p>1. ¿Cuál es la diferencia entre software libre y software de código abierto?<p>El libre se enfoca en la libertad del usuario; el de código abierto en que el código esté disponible, aunque no siempre con todas las libertades.</p>1. ¿Qué es el copyright y cómo se aplica al software?<p>Es el derecho de autor. Protege al creador del software para que otros no copien sin permiso.</p>1. ¿Cómo se pueden proteger los derechos de autor en el software?<p>Registrando el programa y usando licencias que aclaren lo que otros pueden hacer.</p>1. ¿Qué es una patente de software y cómo se aplica?<p>Es un derecho legal que protege una idea o innovación dentro de un software. Solo el dueño puede usarla o venderla.</p>1. ¿Cuáles son las implicaciones legales de utilizar software sin licencia?<p>Es ilegal, puede traer multas, problemas legales y hasta virus o daños al sistema.</p></div><div class="text-box">1. ¿Qué es una licencia de software?<p>Es un permiso que te da el creador para usar un programa bajo ciertas reglas.</p>1. ¿Por qué es importante tener una licencia de software?<p>Porque asegura que uses el software de forma legal y con derechos claros.</p>1. ¿Cuáles son los diferentes tipos de licencias de software?<p>&emsp;Gratuitas, de pago, libres, de código abierto, privativas, entre otras.</p>1. ¿Qué es el código fuente y cómo se relaciona con las licencias de software?<p>Es la base del programa (su “receta”).
